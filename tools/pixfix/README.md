# pixfix — AI 픽셀아트 자동 정리

AI가 만든 "픽셀아트처럼 보이는 큰 그림"을 **진짜 픽셀 격자**로 되돌리고 깔끔하게 정리합니다.
사람·몬스터·아이템·아이콘 등 무엇이든 같은 규칙으로 처리합니다. (1단계: 한 장 정리 + 검사 리포트 · 2단계: 애니메이션 안정화)

## 사용법

```bash
python tools/pixfix/pixfix.py 입력.webp                  # 결과: 입력 옆 pixfix-out/
python tools/pixfix/pixfix.py 입력.png --profile icon -o out/
python tools/pixfix/pixfix.py 폴더/ --profile prop        # 폴더 안 이미지 전부
```

필요한 것: Python 3, `numpy`, `scipy`, `Pillow`

결과 파일 (입력 이름이 `knight.webp`라면)

| 파일 | 내용 |
|---|---|
| `knight.png` | 정리된 스프라이트 시트 (프레임을 가로로 나란히, 발/가운데 기준 정렬) |
| `knight.json` | 프레임 크기·개수·기준점·팔레트 (게임에서 읽을 정보) |
| `knight.report.html` | 검사 리포트: 원본/결과/바뀐 칸/애니메이션/게임 배경 위 모습/팔레트 |
| `knight.report.json` | 리포트 수치 |

## 처리 단계

1. **격자 복원** — 칸 경계에서만 색이 바뀌는 성질로 "픽셀 한 칸이 몇 px인지"와 시작 위치를 찾음. 프레임마다 따로 찾고(AI 그림은 격자가 조금씩 어긋남), 경계를 실제 색 변화 위치에 당겨 맞춘 뒤 칸 가운데 색을 뽑음
2. **배경 제거** — 가장자리 색으로 배경 종류(투명/단색/체크무늬/마젠타 같은 키 색)를 알아내고, 가장자리에서 이어진 배경만 지움. 안쪽에 갇힌 영역은 체크무늬 두 색이 고르게 섞였을 때만 지움 (흰 칼날·흰 눈은 남김). 회색 배경에서 살짝 누런 크림색은 그림으로 봄
3. **팔레트** — 모든 프레임이 한 팔레트를 씀. 눈으로 구분 안 되는 색은 합치고, 몇 칸만 쓰인 비슷한 색은 흡수. 드물어도 확 다른 색(눈, 반짝임)은 남김
4. **청소** — 번진 테두리, 주변과 미세하게만 다른 잡티, 떨어진 먼지 제거
5. **가독성** — 외곽선 줄 한가운데 한 칸 끊긴 곳 잇기. 판타지 아이들 바이옴 배경(하늘·초원·사막·화산·설원·밤) 위에서 실루엣이 묻히는지 검사
6. **애니메이션 안정화** (프레임 2개 이상) — AI는 프레임마다 그림을 새로 그려서 가만히 있는 곳도 칸이 달라 지글거림. 부위 이름 없이 고침:
   - 칸마다 "다른 프레임을 어느 쪽으로 몇 칸 옮기면 여기와 맞나"(움직임)를 찾음 → 숨쉬기로 내려앉은 몸, 흔들린 깃털은 '옮긴 그림'으로 설명됨
   - **strong**: 이 프레임 + 옮긴 다른 프레임들로 칸마다 다수결. 프레임마다 따로 생긴 흔들림은 표가 모자라 지워짐
   - **rebuild**: 기준 프레임 하나만 믿고, 다른 프레임은 '기준 프레임 조각을 1칸 옮긴 것'으로만 다시 만듦 (옮겨서 잘 맞는 곳만 움직임으로 인정). 방패·칼 모양까지 프레임마다 다르게 그린 원본용
   - **auto** (기본): 둘 다 해 보고 결과가 실루엣의 35% 넘게 다르면 rebuild, 아니면 strong
   - 리포트에 깜빡임(앞뒤 프레임은 같은데 가운데만 다른 칸) 전후, 면적 변화, 마지막→첫 프레임 이음새를 표시

원칙: **눈에 띄지 않는 차이만 노이즈로 봄.** 이미 깔끔한 그림을 넣으면 거의 바뀌지 않아야 함.

## 종류 (`--profile`)

| 종류 | 정렬 | 외곽선 | 그 밖 |
|---|---|---|---|
| `character` (기본) | 발 아래 가운데 | 끊긴 곳 이음 | 2칸 이하 먼지 제거, 안정화 auto |
| `prop` | 발 아래 가운데 | 끊긴 곳 이음 | 2칸 이하 먼지 제거, 안정화 auto |
| `icon` | 가운데 | 끊긴 곳 이음 | 프레임 나누지 않음, 먼지 제거 안 함, 안정화 normal |
| `effect` | 가운데 | 손대지 않음 | 먼지 제거 안 함, 안정화 끔 (모양이 크게 변해서) |
| `tile` | 없음 | 손대지 않음 | 배경 제거 안 함, 안정화 끔 |

## 자주 쓰는 옵션

| 옵션 | 언제 |
|---|---|
| `--scale 13` | 격자 신뢰도 경고가 뜰 때 픽셀 크기를 직접 지정 |
| `--native` | 이미 실제 크기 픽셀아트 (자동으로도 알아챔) |
| `--frames 4` / `--frame-size 42x43` / `--single` | 프레임 나누기를 직접 정함 (기본은 빈 틈으로 자동) |
| `--palette 파일` | 게임 마스터 팔레트에 모든 색을 맞춤 (`#hex` 목록 텍스트 또는 PNG) |
| `--outline add` | 외곽선이 없는 그림에 바깥 외곽선을 둘러 줌 |
| `--perfect` | 외곽선 계단의 겹친 L자 칸을 지움 (화풍에 따라. 기본 끔) |
| `--holes` | 한 칸짜리 투명 구멍을 메움 (기본 끔. 눈꽃 같은 일부러 뚫린 칸이 있어서) |
| `--merge 0.06` | 색을 더 줄이고 싶을 때 (기본 0.045) |
| `--stabilize auto\|strong\|normal\|rebuild\|off` | 프레임 안정화 방식. 한 프레임에만 있는 작은 변화(눈 깜빡임 등)를 지키려면 `normal` |
| `--base 2` | rebuild·정렬의 기준 프레임을 직접 고름 (기본은 다른 프레임과 가장 덜 다른 것) |
| `--upscale 6` | 확대본도 함께 저장 |

## 정확도 측정 (`bench/`)

```bash
node tools/pixfix/bench/export_gt.mjs > tools/pixfix/bench/gt.json   # 게임 스프라이트가 바뀌었을 때만
python tools/pixfix/bench/bench.py            # 전부 (107개)
python tools/pixfix/bench/bench.py 20 --show  # 20개만, 하나씩 출력
```

판타지 아이들 스프라이트 106개 + 직접 고친 기사를 정답으로 씀.

- **망가뜨리기 시험**: 정답을 AI 그림처럼 망가뜨림(7~16배 소수점 확대, 칸마다 색 흔들림, 흐림, 잡음, JPEG, 흰색/회색/체크무늬/마젠타 배경) → 되돌려서 비교
- **그대로 두기 시험**: 깨끗한 정답을 넣었을 때 바뀌는 칸 수

현재 (시드 1 / 7)

| 항목 | 결과 |
|---|---|
| 픽셀 크기 맞힘 | 98.1% / 97.2% |
| 모양 일치(IoU) 평균 | 0.987 / 0.984 (중앙값 1.000) |
| 색 일치 | 0.992 / 0.996 |
| 깨끗한 입력에서 바뀐 칸 | 107개 스프라이트 합계 26칸 |

알려진 약점: 2줄짜리처럼 아주 작은 그림, 회색 배경 위의 회색 부분, 외곽선 없는 흰 부분이 흰/체크무늬 배경에 닿은 경우.

### 애니메이션 (`bench_anim.py`)

```bash
python tools/pixfix/bench/bench_anim.py                         # off/normal/strong 비교
python tools/pixfix/bench/bench_anim.py --stabilize auto --redraw 0
```

캐릭터 16종으로 4프레임 idle(기본 / 몸 1칸 내려앉음 / 위쪽 왼편 1칸 흔들림 / 기본)을 만들고, 프레임마다 따로
"다시 그린 흔들림"(명암 덩어리 바뀜, 외곽 들쭉날쭉, 칸 뒤섞임)을 넣은 뒤 한 장으로 망가뜨려 되돌림.

| 방식 | 다시 그린 흔들림 있음 | 흔들림 없음 (진짜 움직임 보존) |
|---|---|---|
| off | 0.782 | 0.978 |
| strong | 0.901 | 0.980 |
| rebuild | 0.809 | 0.964 |
| **auto** | **0.896** | **0.980** |

(칸 정확도 = 정답과 같은 칸 비율)

실제 AI 기사(images 원본 4프레임): 깜빡임 681칸 → auto(rebuild 선택) 29칸. 직접 고친 버전은 53칸.
rebuild는 원본에 없는 움직임을 만들지는 않으므로, AI 프레임이 서로 너무 다르면 거의 멈춘 그림이 됨.
